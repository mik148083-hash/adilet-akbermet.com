АДИЛЕТ & АКБЕРМЕТ — ТОЙ САЙТЫ

1. config.js файлында тойдун күнүн, убактысын, ресторандын атын жана дарегин оңдоңуз.
   Азыркы 2026-12-06 күнү жана «Алина» рестораны — мурунку үлгүдөн алынган, ТАСТЫКТАЛГАН ЭМЕС.
2. https://app.netlify.com/drop сайтына кириңиз.
3. Бул ZIP файлды ачып, ичиндеги adilet-akbermet папкасын Netlify Drop'ко жүктөңүз.
4. Netlify берген *.netlify.app шилтемесин бөлүшүңүз.
5. Коноктордун жоопторун Netlify панелиндеги Forms бөлүмүнөн көрө аласыз (формалар иштетилген болушу керек).
6. adiletakbermet.com деген өзүнчө домен керек болсо, аны сатып алып Netlify'ге туташтыруу зарыл.
