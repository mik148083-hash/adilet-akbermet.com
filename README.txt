АДИЛЕТ & АКБЕРМЕТ — ТОЙГО ЧАКЫРУУ САЙТЫ

Файлдар:
1. index.html — сайттын негизги барагы. GitHub Pages ушул файлды ачат.
2. styles.css — сайттын дизайны жана көрүнүшү.
3. script.js — конвертти ачуу, таймер, музыка баскычтары жана RSVP иш-аракеттери.
4. config.js — музыка жана баштапкы каалоо-тилектердин жөндөөлөрү.
5. thanks.html — өзүнчө рахмат барагы.
6. README.txt — ушул нускама.

GITHUB PAGES'КЕ ЖҮКТӨӨ:
1. Архивди (ZIP) телефонуңузга жүктөп, ичин чыгарыңыз.
2. GitHub репозиторийиңиздин негизги бөлүмүнө (main) кириңиз.
3. Эски index.html, styles.css, script.js жана config.js файлдарын жаңылары менен алмаштырыңыз.
4. Бардык 5 сайт файлын жана README.txt файлын репозиторийдин ROOT бөлүгүнө жүктөңүз.
5. GitHub Pages Settings бөлүмүндө Branch: main жана Folder: /(root) тандалганын текшериңиз.
6. Бир нече мүнөт күтүп, сайтты index.html дареги аркылуу ачыңыз.

МААНИЛҮҮ:
- index.html файлдын атын өзгөртпөңүз.
- Бардык файлдар бир деңгээлде, бир папканын ичинде турушу керек.
- RSVP жооптору азыр браузердин localStorage эс тутумуна сакталат. Башка коноктордун телефондорундагы жооптор жалпы базага автоматтык түрдө чогулбайт.
- Той датасы, убактысы, ресторан жана дарек азыркы HTML файлдагыдай калтырылды.
